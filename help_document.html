NVC User Help Guide

NVC is a Windows-friendly video conversion utility built around FFmpeg. It can watch a source folder, convert supported media into your chosen output format, inspect media metadata, keep logs, generate PC support reports, and optionally clean up original files after conversion.

Important overwrite policy: NVC does not overwrite an already converted video. If the destination already contains video.mp4, the next output becomes video (1).mp4, then video (2).mp4, the same style used by web browsers for duplicate downloads.

Quick Start

  1. Open Settings from the menu.
  2. Choose a Source Folder. This is where new videos will be watched or scanned.
  3. Choose a Destination Folder. Converted videos are written here.
  4. Select the desired output format, codec, bitrate, size, and optional GIF settings.
  5. Click Start to begin monitoring the source folder.
  6. Add or drop supported videos into the source folder. NVC queues and converts them automatically.

Converting Files

Folder Monitoring

When monitoring is active, NVC watches the source folder for new supported videos. Existing files in the source folder are scanned when monitoring starts. Files can also be dragged directly into the app.

Duplicate Files and Output Names

NVC protects existing converted files. If a converted output name already exists, NVC chooses the next available browser-style filename:

  • Session.mp4
  • Session (1).mp4
  • Session (2).mp4

Supported Input Formats

NVC accepts common video formats including MP4, AVI, WMV, MKV, FLV, WebM, MOV, MPEG, MPG, M4V, 3GP, TS, VOB, RM, RMVB, ASF, M2TS, MTS, OGV, DIVX, DV, and F4V.

GPU Encoding

If enabled, NVC attempts to use a supported GPU encoder for NVIDIA, AMD, or Intel hardware. GPU encoding can be much faster than CPU encoding, but available codecs depend on your installed GPU drivers and FFmpeg build.

  • H.264 GPU examples: h264_nvenc, h264_amf, h264_qsv
  • HEVC GPU examples: hevc_nvenc, hevc_amf, hevc_qsv

If the selected GPU encoder is unavailable, NVC falls back to CPU encoding when possible.

GIF Export

GIF output can use a two-pass palette workflow for better color quality. You can adjust FPS, maximum width, looping, and quick mode. Lower FPS and smaller width reduce file size.

Tip: GIF files can become large quickly. For long clips, consider converting to MP4 instead.

Text Overlays

NVC can add overlays such as elapsed time, recorded time, recorded date/time, remaining time, or CRTV-style recording labels. Overlays require video filtering, so they may reduce GPU compatibility and conversion speed.

Media Inspection

The Inspection tab uses FFprobe to show a friendly summary and detailed JSON metadata. The summary includes file duration, size, bitrate, streams, codecs, dimensions, frame rate, audio details, and keyframe estimates.

PC Report Tool

The PC Report tool gathers system information that can help support and troubleshooting. It includes operating system, updates, installed programs, security status, hardware, network, services, processes, environment details, printers, drivers, codecs, and NVC-specific information.

Privacy note: PC reports can include sensitive machine details. NVC redacts common sensitive values such as license keys, serial numbers, MAC addresses, and user profile paths when redaction is enabled. Review any report before sharing it externally.

Lossless Editor

The Lossless Editor tab provides quick FFmpeg stream-copy tools. These operations are fast because they avoid re-encoding when possible.

  • Trim Losslessly: Cuts a section between start and end timestamps using stream copy.
  • Remux: Rewraps media into another container such as MP4, MKV, MOV, or AVI.
  • Extract Audio: Writes the first audio stream to an audio-only file.
  • Remove Audio: Writes a silent video-only copy.
  • Merge Losslessly: Joins compatible clips using FFmpeg's concat demuxer.
Lossless operations require compatible codecs and containers. If FFmpeg fails, the source streams may need re-encoding or a different output container.

Multi-Source Recorder

The Multi-Source Recorder tab is a lightweight recorder for up to four FFmpeg inputs. Enter one source per row and enable the rows you want to record.

  • Use RTSP/HTTP/file URLs directly, for example rtsp://192.168.1.10/stream.
  • Use Windows DirectShow input strings for local capture devices, for example video=Camera Name.
  • Choose copy mode for compatible streams or h264 mode when the source needs encoding.
  • Leave duration blank to record until you press Stop.

Troubleshooting

ProblemWhat To Try
Missing FFmpeg or FFprobeMake sure ffmpeg.exe and ffprobe.exe are included with the app files.
Conversion fails immediatelyCheck the conversion log. Invalid codec/container combinations and custom FFmpeg flags are common causes.
Output file already existsNVC should automatically create a numbered filename. Check the destination folder for (1), (2), etc.
GPU option does not workUpdate GPU drivers, confirm FFmpeg supports your encoder, or disable GPU encoding to use CPU encoding.
App appears idle after dropping a fileConfirm the app is unlocked, monitoring is started, and the file extension is supported.
PC report is slowSome Windows collectors, especially drivers, devices, network connections, and processes, can take time on large systems.

Best Practices

  • Use a dedicated source folder and destination folder.
  • Keep originals until you have confirmed converted files play correctly.
  • Use MP4 with H.264/AAC for broad compatibility.
  • Use HEVC only when smaller files matter and target players support it.
  • Review PC reports before sharing them.
  • Keep custom FFmpeg flags simple and test them on a small file first.

Frequently Asked Questions

Will NVC overwrite my converted videos?

No. NVC creates a numbered filename when an output already exists.

Can I convert files while monitoring is stopped?

Dropped files may be queued and processed when monitoring starts, depending on where they are dropped. Files can also be force-converted through drag/drop paths designed for manual conversion.

Why did my HEVC file fail to play somewhere?

HEVC is efficient but less universally supported than H.264. If compatibility matters, use H.264.

Where are logs stored?

NVC stores logs in its configured log folder, typically under the app data location unless changed by the app configuration.
